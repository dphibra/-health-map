# الخريطة الصحية التفاعلية — محافظة شمال الشرقية

مشروع خريطة تفاعلية لتوزيع المؤسسات الصحية الخاصة (لاحقاً + الحكومية) بمحافظة شمال الشرقية، موجّه للمستثمرين ولدعم قرارات التخطيط الصحي.

## محتويات المشروع
```
index.html              → الصفحة العامة (الخريطة + مصفوفة التغطية) — هذي اللي يشوفها المستثمر/العام
admin.html               → لوحة التحكم (تسجيل دخول + إدارة البيانات)
firebase-config.js        → إعدادات الاتصال بـ Firebase (تحتاج تعبيها بمعلومات مشروعك)
data/institutions.json    → بيانات ابتدائية جاهزة من ملف Excel (82 سجل، 56 مؤسسة)
```

## الخطوة 1: إنشاء مشروع Firebase (مجاني)
1. اذهب إلى https://console.firebase.google.com وأنشئ مشروع جديد.
2. من القائمة الجانبية: **Build → Firestore Database → Create database** — اختر أي موقع قريب (مثل `europe-west` أو `me-central`) واختر **Start in production mode**.
3. من **Build → Authentication → Sign-in method** فعّل **Email/Password**، ثم من تبويب **Users** أضف حسابك (بريدك وكلمة مرور) — هذا هو حساب دخولك للوحة التحكم.
4. من **Project settings (⚙) → General → Your apps** اضغط أيقونة الويب `</>` وسجّل تطبيق جديد، وانسخ القيم التي تظهر لك إلى ملف `firebase-config.js` مكان `YOUR_API_KEY` وبقية القيم.

## الخطوة 2: قواعد الأمان في Firestore
من **Firestore Database → Rules** استبدل القواعد بهذا (قراءة عامة للجميع، وكتابة فقط للمسجّلين دخول):
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /institutions/{docId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```

## الخطوة 3: رفع المشروع على GitHub Pages
1. أنشئ repository جديد على GitHub وارفع كل ملفات هذا المجلد إليه.
2. من إعدادات الـ repo: **Settings → Pages → Source** اختر الفرع `main` والمجلد الجذر `/ (root)`.
3. بعد دقيقة أو دقيقتين، موقعك يصير متاح على رابط من نوع:
   `https://<اسم-المستخدم>.github.io/<اسم-الـ-repo>/`

## الخطوة 4: استيراد البيانات الأولية
1. افتح `admin.html` من موقعك المرفوع، سجّل دخول بالحساب اللي أنشأته بالخطوة 1.
2. اضغط زر **"استيراد أولي من data/institutions.json"** — هذا يرفع الـ 82 سجل دفعة واحدة إلى Firestore.
3. ⚠️ نفّذ هذي الخطوة **مرة واحدة فقط** — تكرارها يكرر السجلات.

## ⚠️ مهم: مواقع تحتاج مراجعة يدوية
عند تنظيف بيانات ملف Excel الأصلي، وُجد أن **45 من أصل 82 سجل** (حوالي 55%) تحتوي على إحداثيات جغرافية غير صحيحة (خارج حدود عُمان تماماً، أو صفر). تم مؤقتاً وضعها في مركز الولاية التقريبي، وتم تعليمها بحقل `needs_location_review = true`.

**كيف تصلحها:**
- من `admin.html` اختر فلتر **"تحتاج مراجعة موقع فقط"** لعرضها كلها.
- لكل سجل، اضغط "تعديل" وحدّث خطي الطول والعرض الصحيحين (تقدر تنسخهم من Google Maps بالضغط بالزر اليمين على الموقع الصحيح ثم "نسخ الإحداثيات").
- بعد التصحيح، السجل يوقف يظهر في هذا الفلتر تلقائياً.

## البيانات الناقصة حالياً
- **ولاية وادي بني خالد:** لا يوجد بها أي مؤسسة صحية خاصة مرخّصة حسب البيانات الحالية — هذي فجوة حقيقية مؤكدة، ستظهر بمصفوفة التغطية كصف كامل باللون الأحمر.
- **بيانات المؤسسات الحكومية:** الحقل `sector` جاهز فيه القيمة `"government"`، بس ما فيه بيانات حكومية مدخلة بعد. أضفها من `admin.html` بنفس الطريقة (زر "+ إضافة مؤسسة جديدة" واختر القطاع "حكومي") فور ما ترسل لي الملف، وبإمكاننا حينها نطوّر مصفوفة التغطية لتقارن خاص/حكومي جنب بعض.
- **بيانات OPD وزيارات العيادات:** لما ترسلها، بنضيف قسم جديد في `index.html` لعرضها كرسوم بيانية منفصلة عن الخريطة (حجم استخدام الخدمة لكل ولاية/عيادة)، مع ربطها بمصفوفة التغطية لتحديد الاحتياج الفعلي مو بس عدد المؤسسات.

## ملاحظة تصميمية
حالياً الموقع يعمل تلقائياً على `data/institutions.json` المحلي إذا لم تربط Firebase بعد — يعني تقدر تجرب الشكل والخريطة فوراً بفتح `index.html` بالمتصفح، وما تحتاج تنتظر إعداد Firebase عشان تشوف النتيجة.
